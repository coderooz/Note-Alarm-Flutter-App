## Reporting Bugs

If you've found a bug, please check the
[existing issues](https://github.com/coderooz/Note-Alarm-Flutter-App/issues)
first to avoid duplicates. If it hasn't been reported, open a new issue using
the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md).

Include as much detail as possible:

- Steps to reproduce
- Expected vs. actual behavior
- Device/emulator and OS version
- Flutter/Dart version (`flutter --version`)
- Screenshots or logs (if applicable)
